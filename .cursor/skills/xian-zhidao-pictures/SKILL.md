# 先知道的圖

這份只負責網頁上的圖。新聞卡片仍照 `xian-zhidao`。

圖要讓人想看，同時一眼就知道：這是給家長的自閉症資訊，不是醫院，也不是兒童遊戲。

## 感覺

明亮、溫暖、有一件正在發生的事。人要有表情，手要伸向他們正在看的東西。

畫面留白可以，但不要大片空顏色、沒有動作。家長進來先看到人，再看到紙、學校、門或書。

## 不要畫

- 拼圖、灰暗走廊、哭臉、隔離的孩子
- 針筒、實驗室器材當主圖
- 整頁只有灰色、米色
- 圖裡寫字。字放在網頁上，不放進圖裡
- 抄別人的圖，或用看起來像照片的圖

首圖要寫替代文字：誰在做什麼。小圖的 `alt` 留空，因為旁邊已有標題。

## 版面風格（2026-10 改版）

整頁走「筆記列表」風，不畫大卡片。畫圖前先記住頁面長這樣，圖才不會跟版面打架：

- **列表取代卡片**：「由新到舊」一則一則上下排，只用一條細線分開。新聞卡沒有白框、沒有圓角、沒有右邊的小插圖。`school.svg`、`service.svg`、`research.svg` 現在不出現在新聞卡裡；`service.svg` 和 `research.svg` 改放在「資料來源」的三格說明裡。
- **等寬字做層次**：日期、地區、「現在可以問」「由新到舊」這些小標題用等寬字（Cascadia Mono 或 Consolas），字距加寬。新聞卡的日期行是灰的，分類是小小的青綠標籤跟在後面。
- **顏色不變**：底色仍是暖紙色 `#f3efe6`，文字墨色 `#1c1915`，連結和重點用青綠 `#0d5c56`。不做深色底。
- **標題大而收**：每則的標題大、行距緊，沒有連結色，游標放上去才出現底線。摘要放淡一點。
- **重點縮成一行**：「資料種類／用不用得上／誰發布」縮成小字排一行，「現在可以做什麼」那一行用淡青綠底的小方塊。
- **「現在可以問」區**：在最上面，兩欄細線分隔的列表，沒有圖，沒有白框。

畫新圖或改圖時，首圖仍放最上面，但窄螢幕下會縮小靠右，畫面主體要畫在左邊，裁掉右邊也不影響。

## 顏色

用這幾色，讓六張圖像同一套：

- 墨色線條 `#24312F`
- 青綠 `#14756C`
- 杏色 `#F6C56A`
- 珊瑚色 `#E37B62`
- 紙色 `#FFFDF9`
- 膚色 `#F6C7A8`

每張圖至少用到青綠、杏色、珊瑚色之中的兩種，線條保持墨色。不要整張只有一種顏色。

## 畫的時候

1. 用 SVG，存進上表的檔名。不改新聞文字，不改版面欄位。
2. 先定「誰在做什麼」，再畫。例如：兩個人一起看紙，不是兩個圓加一個方塊。
3. 頭、身體、手要連在一起。表情用簡單的眼和嘴。
4. 畫完在瀏覽器看首頁、一則卡片，以及窄螢幕。圖不可被裁掉，字不可被圖蓋住。

## 怎樣算好

好：家長和孩子都在笑，手伸向中間那張有綠線的紙，背後有窗和一盆植物。顏色有青綠、杏色、珊瑚。

沉悶，要重畫：只有方框和直線，沒有人；或者全是灰米色，看不出他們在做什麼。
